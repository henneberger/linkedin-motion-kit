# Midnight Signal prompt system

Use these with Codex image generation. Keep the visual grammar fixed and swap only the subject section. Do not ask the model to create the motion; ask it to create a clean still with traceable geometry that the renderer can animate.

## Base style block

```text
Use case: stylized-concept
Asset type: reusable LinkedIn post animation base frame, portrait 4:5
Style/medium: sophisticated editorial 3D illustration blended with crisp vector-like geometry; frosted glass, anodized metal, and soft translucent membranes
Scene/backdrop: deep ink-black to midnight-navy matte field with subtle paper grain and a faint architectural grid
Lighting/mood: restrained cinematic glow; intelligent and technical; not a science-fiction cliché
Color palette: midnight navy and charcoal; electric cyan and warm coral accents; tiny touches of lilac
Composition/framing: centered subject in the middle 75 percent; safe margins; deliberate asymmetry; generous breathing room
Constraints: no text, letters, numbers, logos, or watermark; readable silhouettes; calm uncluttered background
Avoid: stock crypto art, neon overload, circuit-board clichés, robots, brains, dashboards, floating text, lens flares, excessive particles
```

## Subject modules

### Data graph

```text
Subject: 9 to 12 rounded geometric nodes connected by elegant curved and straight filaments; one larger central node and several satellites
Animation affordances: every connection must remain visibly traceable; clear circular node regions for mask-driven pulse and sheen effects
```

### AI model / inference

```text
Subject: a layered translucent model core receiving three narrow input streams and emitting one refined output stream; nested geometric membranes suggest transformation stages
Animation affordances: separated input and output channels; clean central core for a breathing mask; visible stage boundaries for sequential shimmer
```

### Cloud architecture

```text
Subject: a modular cluster of floating service volumes connected through a central routing plane; abstract infrastructure, not literal cloud icons
Animation affordances: clear routes between service volumes; isolated module faces for mask-driven status pulses
```

### Database / event pipeline

```text
Subject: a sequence of five glassy reservoirs connected by precise channels; small abstract data forms transition from raw to ordered along the sequence
Animation affordances: one continuous left-to-right route; isolated reservoirs for staggered pulse masks
```

### Security

```text
Subject: a protected central data lattice surrounded by three offset translucent boundary layers; two clean ingress routes and one rejected route
Animation affordances: uninterrupted boundary contours for orbiting scan particles; visible routes for accepted and rejected flow colors
```

### Developer tooling

```text
Subject: modular abstract building blocks snapping into a stable execution chain; a central compiler-like transformation volume with input and output rails
Animation affordances: discrete module masks; a single readable route through the complete chain
```
